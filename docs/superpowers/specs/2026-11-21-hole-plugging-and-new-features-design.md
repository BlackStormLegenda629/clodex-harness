# Устранение дыр и новые возможности — дизайн

Дата: 2026-11-21. Статус: согласовано с пользователем («сделай план и делай по нему»).

## Намерение

Закрыть найденные разведкой пробелы в трёх направлениях, которые пользователь назвал приоритетными: **оформление**, **работа с кодом**, **надёжность**. Плюс добавить сквозной поиск, которого нет совсем.

## Что нашлось (факты из кода)

- Поиск по чатам — только по заголовку (`ChatScreens.kt:446`). По сообщениям, сессиям, диффам, артефактам и файлам — ничего.
- Агент Code имеет только `workspace_list`, `workspace_read`, `workspace_write` (`CodeAgentTools.kt:134`).
- Переключатели `n1/n2/n3` в «Уведомления» (`SettingsScreens.kt:257`) нигде не читаются; `POST_NOTIFICATIONS` в манифесте нет; единственное уведомление — foreground «Clodex работает».
- `ask`, `edit`, `agentWeb` — мёртвые записи в `TOGGLE_DEFAULTS`; `p1` («Сохранять историю чатов») показан в UI, но не работает.
- `workDirs` из настроек не превращаются в `WorkspaceEntity`, поэтому добавленная там папка не видна Code; при SAF-выборе теряется `treeUri`.
- Нет экспорта/импорта: `allowBackup="false"`, только «Удалить все данные».
- Нет тактильного отклика, монохромной иконки лаунчера, M3 `SearchBar` и голосового вывода.

## Цели

1. Сквозной поиск с одной точкой входа: сообщения, чаты, Code-сессии и диффы, артефакты, файлы рабочей области.
2. Агент получает инструменты `grep` (по regex) и `find` (по имени/glob) с теми же лимитами, что и `read`.
3. Уведомления `n1/n2/n3` становятся рабочими; запрашивается разрешение Android 13+.
4. Мёртвые переключатели удаляются; добавленные папки действительно появляются в Code.
5. Экспорт/импорт чатов, проектов, артефактов, сессий, настроек и памяти через SAF.
6. Оформление: haptic, монохромная иконка, M3 `SearchBar`, озвучка ответов (TTS).
7. Релиз `versionCode 5` с тегом `v1.1` и тем же ключом подписи.

## Не-цели

- Тихая установка APK, root, Shizuku, device owner.
- Запуск команд/сборок/тестов агентом Code (принципиальное ограничение проекта).
- Полнотекстовый индекс FTS и фоновое сканирование — поиск работает по запросу, с лимитами.
- Изменение архитектуры Room (новые таблицы не нужны), смена подписи, новые сетевые возможности.

## Подход и компромиссы

| Решение | Почему |
|---|---|
| Один экран «Поиск» с вкладками вместо луп в каждом разделе | Это и есть «сквозной» поиск; лупы останутся локальными |
| `LIKE` запросы Room + обход файлов по запросу вместо FTS| Для текущего объёма данных достаточно; нет миграций и синхронизации индекса |
|Инструменты `grep`/`find` внутри `WorkspaceOverlay` | Переиспользуют staged-правки и лимиты, не дают агенту прямого FS-доступа |
| Уведомления через отдельный `Notifier` + чистую функцию решения | Тестируемо без Android-устройства |
| Экспорт/импорт — один JSON-пакет с версией схемы | Просто, проверяемо, не тянет новые зависимости |
| Релиз через существующий канал GitHub Releases | Автообновление уже настроено, нужен только новый `versionCode` |

## Ограничения

- minSdk 26, compile/targetSdk 35, Kotlin/Compose, Jetpack Room + DataStore, OkHttp, kotlinx.serialization.
- Все новые строки интерфейса — на русском, в стиле приложения.
- Каждая задача заканчивается тестами и коммитом; полный прогон: `assembleDebug testDebugUnitTest lintDebug`.
- Подпись релиза — тот же ключ `~/clodex-release.jks`, alias `clodex`.
