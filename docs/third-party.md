# Сторонние ресурсы

Лицензия исходного кода Clodex не заменяет лицензии сторонних компонентов. Названия и логотипы провайдеров используются для идентификации сервисов и не подразумевают их одобрения проекта.

Встроенные шрифты распространяются на условиях [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/): Inter, JetBrains Mono, Manrope, Noto Sans, Fira Code, IBM Plex Mono и Source Code Pro. Тексты OFL с уведомлениями собраны в [`licenses/fonts`](../licenses/fonts/).

Логотипы семейств моделей взяты из [Lobe Icons](https://github.com/lobehub/lobe-icons), [лицензия MIT](../licenses/lobe-icons-MIT.txt). Перед публикацией проверьте происхождение остальных иконок и сохраните необходимые уведомления.

Брендовые логотипы коннекторов и неиспользуемые изображения провайдеров удалены из ресурсов: права на их распространение не подтверждены. Вместо них каталог показывает нейтральную цветную плашку с первой буквой названия. Тест `AssetsProvenanceTest` не даёт вернуть такие файлы незаметно.
