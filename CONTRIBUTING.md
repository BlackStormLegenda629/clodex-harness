# Как помочь Clodex Harness

- Для ошибки откройте Issue и укажите версию Clodex, версию Android, шаги, ожидаемый и фактический результат. Перед отправкой удалите из материалов письма, ключи и другие личные данные.
- Для изменения сделайте fork и отдельную ветку. Опишите в Pull Request, зачем нужна правка и как вы её проверили. Если меняется интерфейс, приложите скриншоты со спокойным тестовым содержимым.
- Перед отправкой запустите `./gradlew assembleDebug testDebugUnitTest`. Не добавляйте в Git `local.properties`, файлы подписи, OAuth JSON, токены и собранный APK.
