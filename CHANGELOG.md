# История изменений

## 1.2

- Оболочка приложения переведена на штатные компоненты Material 3: `Scaffold`, `TopAppBar` и `NavigationBar`.
- Экран обновления показывает текущую и новую версии, размер APK и состояние загрузки.
- Сохранён безопасный сценарий обновления через GitHub Releases и системный установщик Android.

## 1.1

- Сквозной поиск по чатам, сообщениям, Code-сессиям, правкам, артефактам и рабочим файлам.
- Code получил поиск по содержимому и именам файлов.
- Рабочие уведомления для подтверждений, завершения сессий и длинных ответов.
- SAF-папки сохраняют tree URI и появляются в Code.
- Экспорт и импорт данных через JSON-файл; импорт добавляет данные и не запускает задания.
- Тактильный отклик, монохромная иконка и озвучка ответов.

## 1.0

- Автопроверка обновлений включена по умолчанию для публичного канала `BlackStormLegenda629/clodex-harness`. Проверка идёт при каждом возврате на передний план, повторяется при сбое сети и показывает «Что нового». APK скачивается только после нажатия «Установить», проверяется подпись и версия, установку подтверждает системный установщик Android. Тихая установка без подтверждения невозможна без root, Shizuku или прав владельца устройства — этих возможностей в Clodex нет.
- Весь интерфейс переведён на Material You: кнопки, иконочные кнопки, чипы и переключатели — штатные компоненты Material 3. Кнопки по умолчанию тональные, карточки лежат на тональной поверхности, строки поиска — пилюли, поля ввода — с плавающей меткой, иконочные плашки — в primary-container. На Android 12 и новее акцент и поверхности берутся из обоев; на более старых версиях используется палитра Material You. Стиль Material You выбирается по умолчанию для новых установок, сохранённые «Классика» и «Студия» не сбрасываются и получают ту же геометрию с прежними палитрами. Семантические цвета диффов и предупреждений не зависят от обоев.
- «Настройки → Программирование» — единая страница с карточками: Caveman, сохранённые разрешения, рабочая область, режим новых сессий Code, модель и поиск, переходы к инструкциям, скиллам и рабочим папкам. Основной экран Code не заменяется. Включённые непустые скиллы добавляются к следующим запросам Chat и Code как инструкции.
- Caveman — набор текстовых инструкций о краткости ответов: установка, уровни Lite/Full/Ultra и пять навыков (коммит, ревью, диагностика, патч, проверка). Стиль не даёт новых инструментов, разрешений или доступа к запуску команд; в общий лимит инструкций 12 000 символов он входит первым и не вытесняется длинными пользовательскими скиллами.
- Брендовые логотипы коннекторов заменены нейтральными цветными плашками с буквой: права на публикацию этих изображений не подтверждены.
- Разрешения изменяющих MCP-инструментов можно запоминать отдельно для каждого чата и отзывать в настройках. Изменение подключения или инструмента не переносит согласие автоматически.
- Редактируемые заметки общей и проектной памяти с поиском и отдельным включением. Chat и Code включают в запрос только разрешённые заметки.
- Запланированные сообщения для чатов: однократно, ежечасно или каждые 24 часа. Android может задерживать отправку; если отправка прервалась, приложение не повторяет её автоматически.
- Code проверяет доступ к рабочей области перед выбором, не перенося незавершённые правки между областями. Настройки разрешений управляют режимом новых сессий Code, а веб-поиск вынесен на отдельный экран.
- Отдельные экраны «Обновления» и «Руководство по настройке», расширенный экран «О приложении».
- Прямой или волнистый индикатор скачивания обновлений с фактическим объёмом загрузки. Опциональное размытие при прокрутке на Android 12 и новее.
- Переключаемый стиль «Студия» с быстрыми подсказками для нового чата. Выбор модели остался у поля ввода.
- Для сборок с настроенным каналом GitHub Releases: уведомление о новом стабильном выпуске и установка через Android.
- Компактное окно «Файлы» в Code.
- HTML-просмотрщик с боковой панелью на планшетах, разворотом на весь экран и подсветкой исходника.
- Реальный веб-поиск через OpenRouter и Anthropic при поддержке провайдера.
- Чат, Code-сессии, проекты, артефакты, MCP-коннекторы и поддержка планшетов.
